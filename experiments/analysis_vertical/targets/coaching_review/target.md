# Coaching Review

## Goal

Assess how the runtime user conducted the meeting, using careful and evidence-grounded coaching language.

## Best Initial Bet

Focus on observable facilitation behaviors instead of personality judgments. This target is likely hard for a small local model because it needs to know which speaker maps to the runtime user and distinguish meeting content from meeting conduct.

## Strengths To Look For

- Uses evidence about facilitation behavior.
- Separates strengths from improvement opportunities.
- Gives practical next-behavior suggestions.

## Weaknesses To Watch

- Coaches the project rather than the meeting conduct.
- Makes generic leadership comments.
- Judges tone or intent without evidence.
